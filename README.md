## 一、项目简介

校园里失物信息分散在班级群、朋友圈，容易被新消息覆盖。本系统把寻物与招领信息集中到一个平台，支持：

- **发布寻物 / 招领信息**：选择类型、填写物品名称、分类、地点、时间、描述、联系方式，可上传照片；
- **集中浏览**：首页按「全部 / 寻物启事 / 招领启事」分类展示信息卡片；
- **关键词搜索**：支持按物品名称、地点、分类、描述搜索，附热门搜索标签与分类筛选；
- **查看详情**：展示物品照片、遗失/拾获地点时间、详细描述、发布者微信号；
- **联系发布者**：一键复制微信号，详情页直接展示联系方式，不做即时聊天；
- **更新状态**：发布者将信息标记为「已找回 / 已归还」，标记后在首页、搜索、详情中同步展示结果，减少重复询问。

**使用技术**：原生 HTML + CSS + JavaScript，无第三方框架、无后端服务器，数据通过浏览器 localStorage 本地持久化。

## 三、使用说明

### 运行方式（仅需两步）

1. **下载**本目录全部文件（保持目录结构不变）；
2. 用**谷歌浏览器（Chrome）** 打开 `index.html`，即可正常使用全部功能。

> 提示：无需安装任何环境、无需联网。数据保存在浏览器本地（localStorage），关闭页面后再打开，发布的记录和状态修改依然保留。

### 功能操作指南

| 操作 | 步骤 |
|---|---|
| 浏览信息 | 打开首页，点击「全部 / 寻物启事 / 招领启事」切换分类浏览 |
| 发布信息 | 点击底部「＋」→ 选择「我丢了东西（寻物）」或「我捡到了东西（招领）」→ 填写必填项（物品名称、地点、时间、联系方式）→ 点击「立即发布」 |
| 搜索信息 | 点击首页顶部搜索框 → 输入关键词（或点击热门标签、分类筛选）→ 查看结果 |
| 查看详情 | 点击首页 / 搜索结果中的信息卡片 → 查看物品详情与发布者微信号 |
| 联系发布者 | 在详情页点击「复制微信号」或「联系拾获者/失主」，即可复制微信号到微信添加 |
| 更新状态 | 进入「我的」→ 找到对应记录 → 点击「标记已找回 / 已归还」 |
| 上传照片 | 发布页点击「上传照片」，选择本地图片（自动压缩为 500px 内 JPEG 保存） |

### 单元测试运行方式

用谷歌浏览器打开 `test/test.html`，页面会显示全部用例执行结果（通过 / 失败数量与明细）。

## 四、设计说明

- **状态闭环**：发布 → 浏览/搜索 → 详情 → 复制微信联系 → 标记「已找回/已归还」，标记结果在首页、搜索、详情同步可见，解决「联系之后信息如何结束」的问题；
- **附加特点**：
  1. 一键复制微信号（详情页 + 联系按钮）；
  2. 按物品分类筛选 + 热门搜索标签；
  3. 发布表单完整校验（必填项、长度限制）与错误提示；
  4. 搜索无结果、列表为空时的友好空状态提示；
  5. 已解决信息在列表中置灰淡化，状态一目了然；
  6. 照片上传自动压缩，不依赖任何外部图片服务。
